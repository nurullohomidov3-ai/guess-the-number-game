# Игра «Угадай число» (Guess The Number)

Консольная игра на C#, разработанная с применением принципов SOLID и событийной модели (паттерн Наблюдатель).

## Возможности
- Выбор уровня сложности и пользовательские настройки диапазона чисел.
- Подсказки «больше» или «меньше» после каждой попытки.
- Уведомления о ходе игры через события (Events).
- Сохранение статистики игр в файл (`statistics.json`).

## Запуск проекта
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Откройте файл `GuessTheNumber.slnx` в Visual Studio или выполните в терминале команду:
   ```bash
   dotnet run
   ```
